# GitHub Pages Deployment Guide

Your wedding invitation website is now ready to be deployed on GitHub Pages!

## 🚀 Enable GitHub Pages

Follow these steps to deploy your site:

### Step 1: Go to Repository Settings
1. Go to your repository: https://github.com/sashakura/wedding-invitation
2. Click on the **Settings** tab (top right)

### Step 2: Enable GitHub Pages
1. Scroll down to **Pages** section (left sidebar)
2. Under "Build and deployment", select:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main`
   - **Folder**: `/ (root)`
3. Click **Save**

### Step 3: Wait for Deployment
- GitHub will automatically build and deploy your site
- You'll see a green checkmark when it's live
- This typically takes 1-2 minutes

### ✅ Your Live URL Will Be:
🌐 **https://sashakura.github.io/wedding-invitation/**
